# المرحلة الثامنة: إشعارات داخل الموقع وإدارة فئات الدعم

هذه الحزمة مبنية على نسخة المرحلة السادسة المرفقة. المرحلة السابعة (إشعارات البريد) متخطاة عمدًا، ولا تتضمن تغييرات على SMTP أو وظائف إرسال البريد.

## ما تضيفه

- إشعارات داخل الموقع للعميل عند رد فريق الدعم أو تغيير حالة التذكرة.
- إشعارات داخل الموقع لموظف الدعم عند وصول تذكرة أو رد عميل، وعند إسناد تذكرة أو تحديث حالتها. تُحترم خانة استقبال إشعارات التطبيق للموظف.
- جرس إشعارات في الصفحات العامة وصفحات الدعم ولوحة الإدارة؛ العدد يتحدث لحظيًا، والإشعار يفتح محادثة التذكرة. يمكن تحديد الكل كمقروء.
- صفحة «إدارة فئات الدعم» لمالك الموقع فقط، لإضافة وتعديل وترتيب وتفعيل/إيقاف الفئات والفئات الفرعية. لا تُحذف الفئات المستخدمة حتى لا تتأثر التذاكر القديمة.
- نموذج التذكرة ولوحة الموظف يحدّثان قائمة الفئات عند تغيرها.

## طريقة التثبيت

1. افتح مشروع Supabase الصحيح، ثم SQL Editor.
2. افتح `migration_support_8_notifications_categories.sql` من هذا المجلد، والصق محتواه كاملًا، ثم اضغط Run مرة واحدة.
3. انشر ملفات الموقع من جذر المشروع بالطريقة المعتادة (GitHub Pages / Cloudflare حسب إعداد مشروعك).
4. سجّل الدخول بحساب مالك الموقع، ثم لوحة الإدارة ← إدارة فئات الدعم. جرّب تحديث اسم/ترتيب فئة، ثم افتح مركز الدعم في جلسة أخرى وتأكد من ظهور التحديث.
5. أنشئ تذكرة بحساب عميل، ورد عليها من حساب موظف، وغيّر حالتها؛ تحقق من ظهور الإشعارات عند الطرف المناسب.

## التحقق والقيود

تم تضمين تريجرات قاعدة البيانات وتحديثات واجهة الموقع في هذه الحزمة. يجب تشغيل ملف SQL ونشر الموقع حتى تصبح المرحلة فعالة. لا أستطيع التحقق من مشروع Supabase الحي من هذه النسخة المحلية. الإشعارات لا تحتوي نص الرسالة أو مرفقاتها؛ تعرض نوع الحدث ورقم/عنوان التذكرة فقط.
