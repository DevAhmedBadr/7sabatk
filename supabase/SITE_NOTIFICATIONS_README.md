# إشعارات عامة من لوحة المالك

## الميزة

- صفحة جديدة في لوحة الإدارة باسم «إرسال إشعار للمستخدمين»، لا تظهر إلا لمالك الموقع.
- إرسال عنوان ونص إلى جميع الحسابات النشطة، أو تحديد حساب واحد أو أكثر بالـ username.
- ظهور الإشعار في جرس الموقع فورًا، مع تحديث لحظي، وإمكانية تحديده كمقروء.
- إشعارات الدعم الفني تظل كما هي وتظهر في نفس الجرس.

## التفعيل

1. في Supabase SQL Editor شغّل `migration_admin_site_notifications.sql` كاملًا.
2. انشر ملفات الموقع من جذر النسخة الجديدة.
3. سجّل الدخول كمالك وافتح لوحة الإدارة، ثم «إرسال إشعار للمستخدمين».
4. أرسل إشعارًا تجريبيًا إلى username معروف، وتحقق من ظهوره بحساب ذلك المستخدم. بعد ذلك جرّب خيار كل الحسابات النشطة.

لا يحتاج هذا التغيير إلى إعادة نشر Edge Function. قاعدة البيانات تتحقق من هوية المالك قبل الإرسال، ولا تمنح المستخدمين صلاحية إدراج الإشعارات مباشرة. كل مستخدم يستطيع قراءة إشعاراته فقط وتحديث حالة قراءتها. الإرسال داخل الموقع ولا يرسل بريدًا إلكترونيًا.
