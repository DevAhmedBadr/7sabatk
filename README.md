# Digital Hub — النسخة المنظمة

موقع كتالوج عربي بالكامل، بتصميم داكن ومتجاوب، ومقسّم إلى ملفات مستقلة.

## هيكل المشروع

```text
digital-hub/
├── index.html
├── data/
│   └── accounts.json       # قاعدة بيانات الكتالوج البسيطة
└── assets/
    ├── css/
    │   └── style.css       # كل التنسيقات
    └── js/
        ├── app.js          # تشغيل الموقع والبحث والتصفية
        ├── data.js         # تحميل البيانات
        ├── render.js       # إنشاء البطاقات والتفاصيل
        └── settings.js     # بيانات التواصل
```

## قاعدة البيانات السهلة

افتح `data/accounts.json` من GitHub واضغط Edit. أضف عنصرًا جديدًا داخل مصفوفة `accounts`، ثم Commit changes.

مثال:

```json
{
  "id": "DH-003",
  "title": "اسم العرض",
  "username": "@username",
  "category": "ترفيه",
  "followers": 12000,
  "averageViews": 30000,
  "engagement": "5.4%",
  "image": "https://example.com/image.jpg",
  "description": "وصف مختصر للمعلومات العامة.",
  "createdAt": "2026-10-31"
}
```

ملاحظات:
- ضع فاصلة بين العناصر داخل المصفوفة، ولا تضع فاصلة بعد آخر عنصر.
- `image` رابط صورة مباشر، أو اتركه فارغًا.
- `followers` و`averageViews` أرقام فقط بدون فواصل أو نصوص.
- غيّر بيانات الأمثلة التجريبية أو احذفها قبل الإطلاق.
- يجب أن تكون الصور والمعلومات مصرحًا لك بنشرها.

## إعداد التواصل

افتح `assets/js/settings.js` وضع رقم واتساب الدولي بدون + أو مسافات، أو بريد التواصل. مثال توضيحي فقط: `201012345678`.

## النشر على GitHub Pages

1. افتح مستودع GitHub باسم `digital-hub`.
2. ارفع محتويات هذا المجلد إلى جذر المستودع، مع الحفاظ على نفس أسماء المجلدات.
3. وافق على استبدال `index.html` القديم.
4. اترك إعدادات Pages كما هي: `main` و`/(root)`.
5. انتظر انتهاء النشر، ثم افتح رابط الموقع واعمل تحديثًا قويًا Ctrl+F5.

## ملاحظة تقنية

GitHub Pages استضافة ثابتة؛ لذلك ملف JSON هنا هو قاعدة بيانات كتالوج بسيطة (ملف بيانات)، وليس قاعدة بيانات خادمية أو لوحة إدارة آمنة. لا تخزن كلمات مرور أو رموز استرداد أو معلومات خاصة. كل ما تضيفه سيكون عامًا للزوار.
